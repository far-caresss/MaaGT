## 1. 需求（用户原话要点）

开发游戏《坎特伯雷公主与骑士唤醒冠军之剑的奇妙冒险》（Guardian Tales / 坎公骑冠剑）的**公会协力讨伐**自动化：

- 每期有 4 个 BOSS，每个 BOSS 属性不同
- **自动识别每个 BOSS 的属性**
- 在配置页面配置已有队伍的属性
- 计算后让队伍去打**其克制的 BOSS**
- 若某 BOSS 没有能克制它的队伍，则用**不被它克制**的队伍去打
- **初版先跑「演习」而不是「入场」**，验证可行后再切入场
- 先用 3 个队伍试：土远(土) / 暗近(暗) / 虚勇虚近(虚)

### ⚠️ 首次使用：必须手动创建 `assets/config/teams.json`

`.gitignore` 末尾的 `config` 规则把 `assets/config/` 整个目录排除了

clone 下来后不建这个文件，`load_teams()` 会失败、任务直接终止。

```jsonc
{
    // name    : 游戏内「选择预设」弹窗里的预设名（代码用它 OCR 定位并点击该行）
    // element : fire / water / earth / light / dark / virtual
    // 注意：
    //   - 数组顺序 = 平局时的优先级（靠前的优先出战）
    //   - 未配置完（带红点）的预设请勿写入
    //   - 队伍英雄不要跨预设重复（同一个英雄只能在 1 个预设里）
    "teams": [
        { "name": "土远", "element": "earth" },
        { "name": "暗近", "element": "dark" },
        { "name": "虚勇虚近", "element": "virtual" }
    ]
}
```

（字段含义的完整设计说明见 `docs/zh_cn/公会协力讨伐-设计方案.md` 第五节。）

**新增命令行联调脚本** `_tmp\run_raid.py`（绕过 VS Code 插件，抓完整输出，排障神器）
—— 架构与插件一致：本进程做 framework（Resource/Controller/Tasker），
`agent/main.py` 作为 AgentServer 子进程跑，用 `AgentClient` 连接。

```powershell
$env:PYTHONIOENCODING='utf-8'
python _tmp\run_raid.py --no-run   # 自检：加载资源/连设备/拉起 agent，不执行任务
python _tmp\run_raid.py --probe    # 只读探测：打印各识别节点命中情况（判断当前在哪个页面）

```

⚠️ 踩坑：`maa` 包随 `import` 的模块不同会切到 AgentServer 模式
（`maa/agent/__init__.py` 调 `Library.open(agent_server=True)`），
一旦切过去 `Resource()` 就会报 `Failed to create resource`。
所以 **framework 侧的 `Resource/Tasker/Controller` 必须在 import 任何 agent 模块之前创建**。

## 5. 算法

```
克制环：火→土→水→火 ； 光→暗→虚→光
关系：counter(队伍克 BOSS) / neutral / countered(被克)
choose_plan 目标（字典序）：
  1. 最大化「克制」对数
  2. 最大化「中性」对数（等价于最小化「被克」对数）
  3. 平局 → 用 teams.json 里靠前的队伍
约束：BOSS 不重复、队伍不重复；场数 = min(剩余次数, BOSS 数, 队伍数)
```

**属性识别**：从图标 ROI 提取 24x24 白色字形，与 6 张模板算 IoU，取最高且 ≥0.55。
实测 IoU 0.70–0.85，次优仅 0.31–0.39，分辨度足够。

## 8. 踩坑记录（重要）

### 编排类

- **页面切换必须轮询等待**：退出战斗 → 回首领列表 有动画/奖励弹窗，只截图一次判页会误判，
  然后拿村庄坐标乱点 → 越走越偏。用 `_wait_boss_list(timeout)` 轮询解决。
- **OCR 节点别用 `expected` 硬匹配**：匹配失败 → `hit=False` → 误判整页。
  改成去掉 expected、Python 侧正则解析，鲁棒得多。
- **maa 反序列化后 `result.box` 是 `list` 不是 `Rect`** → 必须用 `_to_box()` 兼容。
- 插件会吞掉 Agent 的 stdout → **必须自己落盘** `debug/guild_raid.log`（含 traceback）。

### 编辑类

- ⚠️ **`replace_string_in_file` 对 `guild_raid.py` 造成过 4 次多行文本错位损坏**
  → 只用极短单行 oldString，或整文件重写；**每次编辑后必须 `py_compile` 验证**。

### 终端类

- ~~终端沙箱损坏（`BaseContainer is unavailable`）~~ → **2026-10-02 已由用户修好**，终端可正常用。
- 仍建议：调用 `.ps1` 前 `Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass -Force`
- **控制台中文乱码**：PowerShell 默认 GBK 读 UTF-8 文件会花屏。
  先 `[Console]::OutputEncoding=[System.Text.Encoding]::UTF8`，
  `Get-Content` 加 `-Encoding UTF8`，python 加 `$env:PYTHONIOENCODING='utf-8'`
- `Save-Crop` 越界会报"内存不足"，须保证 x+w ≤ 1280、y+h ≤ 720

### 游戏行为

- **在村庄界面按返回键会弹「确定退出游戏？」** → 代码里不可盲目按返回键
- 每期 BOSS 名字与形象都会变 → **禁止依赖 BOSS 名字**（不 OCR 名字、不写死点击坐标）
